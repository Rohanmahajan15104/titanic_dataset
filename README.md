# Titanic Dataset Analysis
This project analyzes the Titanic dataset using Python. The goal is to explore the dataset, clean missing data, visualize important patterns, and understand the factors that influenced passenger survival.

🚀 Features
- Load and explore the Titanic dataset
- Handle missing values
- Remove duplicate records
- Perform exploratory data analysis (EDA)
- Create visualizations using Matplotlib and Seaborn
- Generate summary statistics
- Identify factors affecting survival

 🛠️ Tech Stack
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

📂 Project Structure

│── Titanic_Analysis.ipynb

📊 Analysis Performed
- Dataset overview
- Missing value analysis
- Data cleaning
- Survival count visualization
- Age distribution
- Gender vs Survival
- Passenger Class vs Survival
- Correlation heatmap

📚 Dataset
The dataset used is the Titanic dataset, commonly available on Kaggle.
